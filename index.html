แบบสำรวจความต้องการสนับสนุนเพิ่มเติมจากฝ่าย Admin Support

เพื่อพัฒนาการบริการเชิงรุก และสนับสนุนการทำงานของท่านให้ดียิ่งขึ้น หน่วยงาน Admin Support ขอรวบรวมความต้องการเพิ่มเติมจากบริการที่เรามีอยู่ในปัจจุบัน ความคิดเห็นของท่านจะถูกนำไปใช้ในการวางแผนปรับปรุงการบริการในไตรมาสถัดไป

✅ ขอขอบคุณสำหรับข้อเสนอแนะอันเป็นประโยชน์ ทีมงาน Admin Support จะนำข้อมูลของท่านไปพิจารณาเพื่อวางแผนและพัฒนาการบริการให้ดียิ่งขึ้นต่อไป

Section 1: ข้อมูลเบื้องต้น

กรุณากรอกข้อมูลเพื่อประโยชน์ในการวิเคราะห์ข้อมูล

แผนก/ฝ่าย *

Section 2: ความต้องการสนับสนุนเพิ่มเติม

โปรดเลือกคำตอบที่ตรงกับความต้องการของท่านมากที่สุด

1. นอกเหนือจากการจองห้องประชุมตามปกติ หาก Admin Support มีบริการ "ช่วยเตรียมความพร้อมสำหรับการประชุม" ท่านต้องการให้เราสนับสนุนด้านใดเป็นพิเศษ? (เลือกได้สูงสุด 2 ข้อ) *

วัตถุประสงค์: ต่อยอดจากการบริการ "จองห้องประชุม" ไปสู่บริการที่ครบวงจรมากขึ้น เพื่อลดภาระให้พนักงาน

เลือกแล้ว: 0/2 ข้อ
กรุณาเลือกอย่างน้อย 1 ข้อ และไม่เกิน 2 ข้อ

2. เพื่อให้การเบิกจ่ายพัสดุและอุปกรณ์สำนักงานมีประสิทธิภาพยิ่งขึ้น ท่านต้องการให้มีบริการหรือข้อมูลใดเพิ่มเติมมากที่สุด? *

วัตถุประสงค์: หาแนวทางปรับปรุงกระบวนการเบิกจ่าย โดยเน้นการให้ข้อมูลเชิงรุกและลดขั้นตอนที่ซ้ำซ้อน

3. ในด้านการประสานงานอาคารสถานที่ หากมีบริการ "ตรวจเช็คพื้นที่ทำงานเชิงรุก" ท่านอยากให้เราให้ความสำคัญกับเรื่องใดเป็นอันดับแรก? *

วัตถุประสงค์: เปลี่ยนจากการรอ "แจ้งซ่อม" เป็นการเข้าไปดูแลและป้องกันปัญหาล่วงหน้า

Section 3: ข้อเสนอแนะเพื่อการพัฒนา

ความคิดเห็นของท่านมีค่าอย่างยิ่งต่อการพัฒนาบริการของเรา

4. จากบริการทั้งหมดของ Admin Support มีกระบวนการหรือขั้นตอนใดที่ท่านรู้สึกว่า "สามารถทำให้ง่ายขึ้น" หรือ "เป็นระบบดิจิทัล" ได้อีกบ้าง?

วัตถุประสงค์: รวบรวมไอเดียในการปรับปรุงกระบวนการทำงานและนำเทคโนโลยีมาใช้

5. หากท่านสามารถเสนอ "บริการใหม่" 1 อย่างที่อยากให้ Admin Support ทำให้ เพื่อช่วยให้การทำงานของท่านสะดวกสบายและมีประสิทธิภาพมากขึ้น บริการนั้นคืออะไร?

วัตถุประสงค์: เปิดโอกาสให้พนักงานได้แสดงความคิดเห็นและความต้องการที่ยังไม่เคยถูกค้นพบ (Unmet Needs)
